# Remote renderer development, October 29

This work has no genuine game launch or supervisor submission path. Original
images, saves, supervisor policy, breakpoints, authorization history, consumed
candidates, and the separately qualified SetMaterial package remain read-only.

Results: [report](../../../../out/recovery/d3d8-remote-20261029-01/REPORT.txt).
The fresh combined candidate retains the measured material bridge and eight
previous states. **No new native operation is enabled.** The exact CreateDevice
tuple failed in both native architectures in the current RDP session, so
SetRenderState(148,1), (145,0), and later calls remain guarded.

The phase uses these drivers:

- `phase.py`: exclusively create preservation, native environment probes, and
  non-graphical adapter contract builds; verify preserved trees at completion.
- `static_plan.py` and `coverage.py`: original PE disassembly, generated-source
  correspondence, full SetRes tail/cache/gamma and outer initialization inventory.
- `adapter_contract.c`: exact staged adapter source against explicitly synthetic
  COM and GUI services; validates guest frame/CPU, return propagation, ownership,
  memory and unsupported guards. It does not qualify DXVK or Windows callbacks.
- `prepare_batches.py` and `batch_oracle.c`: compile future native state, sampler,
  transform and null-binding measurements. Only `--abi-only` ran remotely; this
  mode loads no graphics DLL and uses local test functions.
- `candidate.py`: verify all 279 reused object hashes, unchanged source/header
  trees and original compile lineage; relink to fresh paths; inspect PE/PDB
  identity and generated marker offline. It changes no breakpoint.
- `evidence_audit.py`: recheck copies of historical material evidence; explicitly
  separate from fresh graphics testing.
- `finalize.py`: collect the final source snapshot, limitations, provenance,
  ordered plan and integrity results.

Output names are exclusive. Use fresh phase/build/fixture directories for a
future reproduction. Failed setup output is retained separately. Do not rerun
the preservation/build actions into these existing directories.

When physical access resumes, start with the already compiled single-state
native fixtures for `(148,1)` on x86/x64, then the prepared `states` batch. Native
readback and ABI/FPU comparison must pass before extending a production allowlist
or qualifying a translated graphics fixture. The sampler/binding fixture domains
are measurement samples, not declarations of supported production inputs. Gamma
requires a separate measured/restoring fixture; no gamma test was run here.

The combined executable is unexecuted, unconsumed and not supervisor-qualified.
The existing supervisor endpoint and historical failures remain unchanged.
